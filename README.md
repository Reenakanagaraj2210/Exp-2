# Exp - 2 LIBRARY MANAGEMENT SYSTEM

# AIM:
To develop the Library Management System using Star UML.
# SRS (Procedure):
1.Identify the requirements of the Library Management System, such as searching, borrowing, returning and paying fines for books.
2.Identify the actors involved in the system, mainly Student and Staff/Librarian.
3.Prepare the Use Case Diagram to represent the interaction between the actors and the library system.
4.Identify the classes required for the system, such as Book, Student, Staff, Library and Transaction.
5.Prepare the Class Diagram showing the attributes, operations and relationships between the classes.
6.Prepare the Sequence Diagram to represent the sequence of interactions between the user and the system for activities such as borrowing and returning books.
7.Prepare the Activity Diagram to show the workflow of library activities such as searching, borrowing and returning books.
8.Prepare the Communication Diagram to represent the communication between objects during library operations.
9.Design all the UML diagrams using StarUML and establish the required relationships between actors, classes and objects.
10. Verify the diagrams to ensure that all requirements and interactions of the Library Management System are properly represented.
